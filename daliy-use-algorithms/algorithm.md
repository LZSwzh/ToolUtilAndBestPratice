# 工作常用算法


## 状态管理类
### 状态机算法
基本思想：
根据当前的状态和输入的事件，从一个状态转移到另一个状态。常用于对状态的流转进行解耦
使代码逻辑更加清晰,且易于维护

分类：
- F(s) -> (a.s`)型状态机(摩尔机),状态的转移仅仅依赖当前状态
- F(s,e)->(a,s`)型状态机(米利机),状态转移除了依赖当前状态还依赖当前输入值

基本组成：
- 状态:包括现态和次态,现态-现在所处的状态,次态-满足后迁移到新的状态
- 事件:也叫条件，当条件被满足可能触发一个动作或者触发一次状态的转移
- 动作:满足后执行的动作,动作执行后可以转换状态也可以不转换。动作不是必须的,满足条件后可以不做动作直接转移状态
- 转换:从现态转换到次态的过程
